# Especificação: Internacionalização (i18n) — Type-Safe com Next.js App Router

**Data:** 2026-10-19  
**Status:** Aprovado  
**Branch:** `feature/animations-and-internacionalization`  
**Abordagem:** Next.js nativo com `app/[lang]/` + JSON type-safe  
**Locales:** `pt-BR` (padrão) e `en`

---

## 1. Objetivo

Adicionar suporte a múltiplos idiomas (português e inglês) ao portfólio, permitindo que o usuário troque de idioma via botão no header e que as URLs sejam prefixadas com o locale (`/pt-BR/...`, `/en/...`).

Todo o texto da interface (navegação, páginas, formulários, descrições de projetos, case studies) deve ser traduzível. O conteúdo dos projetos (títulos, descrições, intros, tags, seções) também será internacionalizado.

---

## 2. Decisões Técnicas

| Aspecto | Decisão | Justificativa |
|---------|---------|---------------|
| **Roteamento** | `app/[lang]/` com `proxy.ts` | Nativo do Next.js 16, SEO-friendly, URLs limpas |
| **Troca de idioma** | Cookie `NEXT_LOCALE` + botão no header | Persiste preferência, troca instantânea via redirect |
| **Arquivos de tradução** | JSON em `/dictionaries/` | Simples, versionável, fácil de editar |
| **Type-safety** | `typeof ptBR` como tipo base | TypeScript valida `en.json` contra `pt-BR.json` em build time |
| **Server Components** | `getDictionary(lang)` direto | Sem overhead de context no server |
| **Client Components** | `I18nProvider` + `useTranslations()` | Context React para componentes interativos |
| **Projetos** | Metadados em `lib/projects.ts`, textos no dicionário | Separação clara: estrutura vs. conteúdo |
| **Metadata/SEO** | `generateMetadata` por locale + `alternates.languages` | SEO correto para cada idioma |

```ts
import 'server-only';
import type { Locale } from './config';
import ptBR from '@/dictionaries/pt-BR.json';

// Type-safety: tipo inferido do pt-BR.json
export type Dictionary = typeof ptBR;

const dictionaries = {
  'pt-BR': () => import('@/dictionaries/pt-BR.json').then((m) => m.default as Dictionary),
  en: () => import('@/dictionaries/en.json').then((m) => m.default as Dictionary),
} satisfies Record<Locale, () => Promise<Dictionary>>;

export type { Locale };
export const isLocale = (lang: string): lang is Locale =>
  lang === 'pt-BR' || lang === 'en';

export const getDictionary = async (locale: Locale): Promise<Dictionary> =>
  dictionaries[locale]();
```

### 4.3. `proxy.ts` (raiz do projeto)

```ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { locales, defaultLocale, type Locale } from './i18n/config';

const PUBLIC_FILE = /\.(.*)$/;

export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Ignora arquivos públicos, _next, etc.
  if (pathname.startsWith('/_next') || PUBLIC_FILE.test(pathname)) {
    return;
  }

  // Já tem locale na URL? Deixa passar.
  const pathnameHasLocale = locales.some(
    (locale) => pathname.startsWith(`/${locale}/`) || pathname === `/${locale}`
  );
  if (pathnameHasLocale) return;

  // Detecta locale: cookie > Accept-Language > default
  const cookieLocale = request.cookies.get('NEXT_LOCALE')?.value;
  const acceptLang = request.headers.get('accept-language') ?? '';

  let locale: Locale = defaultLocale;
  if (cookieLocale && locales.includes(cookieLocale as Locale)) {
    locale = cookieLocale as Locale;
  } else if (acceptLang.toLowerCase().includes('en')) {
    locale = 'en';
  }

  // Redireciona: /contato → /pt-BR/contato (ou /en/contato)
  request.nextUrl.pathname = `/${locale}${pathname}`;
  return NextResponse.redirect(request.nextUrl);
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
};
```

### 4.4. `lib/i18n/provider.tsx`

```tsx
'use client';

import { createContext, useContext, type ReactNode } from 'react';
import type { Dictionary, Locale } from '@/i18n/dictionaries';

type I18nContextValue = {
  dict: Dictionary;
  locale: Locale;
};

const I18nContext = createContext<I18nContextValue | null>(null);

export function I18nProvider({
  dict,
  locale,
  children,
}: {
  dict: Dictionary;
  locale: Locale;
  children: ReactNode;
}) {
  return (
    <I18nContext.Provider value={{ dict, locale }}>
      {children}
    </I18nContext.Provider>
  );
}

export function useI18n() {
  const ctx = useContext(I18nContext);
  if (!ctx) throw new Error('useI18n must be used within I18nProvider');
  return ctx;
}
```

### 4.5. `lib/i18n/use-translation.ts`

```ts
'use client';

import { useI18n } from './provider';
import type { Dictionary } from '@/i18n/dictionaries';

// Gera tipo de todas as chaves possíveis (dot-notation)
type Path<T, P extends string = ''> = T extends string
  ? P
  : T extends object
    ? { [K in keyof T & string]: Path<T[K], P extends '' ? K : `${P}.${K}`> }[keyof T & string]
    : never;

export type TranslationKey = Path<Dictionary>;

// Hook para Client Components
export function useTranslations() {
  const { dict, locale } = useI18n();

  const t = (key: TranslationKey): string => {
    const value = key.split('.').reduce<unknown>((obj, k) => {
      if (obj && typeof obj === 'object' && k in obj) {
        return (obj as Record<string, unknown>)[k];
      }
      return undefined;
    }, dict);

    if (typeof value !== 'string') {
      console.warn(`Missing translation: ${key} (locale: ${locale})`);
      return key;
    }
    return value;
  };

  return { t, locale, dict };
}

// Helper para Server Components
export function createTranslator(dict: Dictionary, locale: string) {
  return (key: TranslationKey): string => {
    const value = key.split('.').reduce<unknown>((obj, k) => {
      if (obj && typeof obj === 'object' && k in obj) {
        return (obj as Record<string, unknown>)[k];
      }
      return undefined;
    }, dict);

    if (typeof value !== 'string') {
      console.warn(`Missing translation: ${key} (locale: ${locale})`);
      return key;
    }
    return value;
  };
}
```

### 4.6. `components/layout/LanguageSwitcher.tsx`

```tsx
'use client';

import { usePathname, useRouter } from 'next/navigation';
import { locales, localeNames, type Locale } from '@/i18n/config';

export function LanguageSwitcher({ currentLocale }: { currentLocale: Locale }) {
  const pathname = usePathname();
  const router = useRouter();

  const switchLocale = (newLocale: Locale) => {
    // Persiste preferência no cookie (1 ano)
    document.cookie = `NEXT_LOCALE=${newLocale}; path=/; max-age=31536000; SameSite=Lax`;

    // Troca o prefixo de locale na URL
    const segments = pathname.split('/');
    segments[1] = newLocale;
    const newPath = segments.join('/');

    router.push(newPath);
    router.refresh();
  };

  return (
    <div className="flex items-center gap-1 rounded-full bg-[color:var(--color-blue-soft)]/30 p-1">
      {locales.map((locale) => (
        <button
          key={locale}
          onClick={() => switchLocale(locale)}
          aria-label={`Mudar para ${localeNames[locale]}`}
          aria-pressed={locale === currentLocale}
          className={`rounded-full px-3 py-1 text-sm transition-all ${
            locale === currentLocale
              ? 'bg-[color:var(--color-blue)] text-[color:var(--color-cream)] font-bold'
              : 'text-[color:var(--color-blue)] hover:bg-[color:var(--color-blue-soft)]/50 font-normal'
          }`}
        >
          {localeNames[locale]}
        </button>
      ))}
    </div>
  );
}
```

### 4.7. `app/[lang]/layout.tsx`

```tsx
import type { Metadata } from 'next';
import { notFound } from 'next/navigation';
import { getDictionary, isLocale } from '@/i18n/dictionaries';
import { locales } from '@/i18n/config';
import { Header } from '@/components/layout/Header';
import { Footer } from '@/components/layout/Footer';
import { I18nProvider } from '@/lib/i18n/provider';
import './globals.css';

export async function generateStaticParams() {
  return locales.map((lang) => ({ lang }));
}

export async function generateMetadata({
  params,
}: {
  params: Promise<{ lang: string }>;
}): Promise<Metadata> {
  const { lang } = await params;
  if (!isLocale(lang)) return {};

  const dict = await getDictionary(lang);

  return {
    title: {
      default: dict.site.name,
      template: `%s · ${dict.site.name}`,
    },
    description: dict.site.tagline,
    openGraph: {
      title: dict.site.name,
      description: dict.site.tagline,
      locale: lang === 'pt-BR' ? 'pt_BR' : 'en_US',
      type: 'website',
    },
    alternates: {
      languages: {
        'pt-BR': '/pt-BR',
        en: '/en',
      },
    },
  };
}

const TYPEKIT_ID = process.env.NEXT_PUBLIC_TYPEKIT_ID;

export default async function RootLayout({
  children,
  params,
}: Readonly<{
  children: React.ReactNode;
  params: Promise<{ lang: string }>;
}>) {
  const { lang } = await params;
  if (!isLocale(lang)) notFound();

  const dict = await getDictionary(lang);

  return (
    <html lang={lang} className="h-full" suppressHydrationWarning>
      <head>
        {TYPEKIT_ID ? (
          <>
            <link rel="preconnect" href="https://use.typekit.net" />
            <link
              rel="stylesheet"
              href={`https://use.typekit.net/${TYPEKIT_ID}.css`}
            />
          </>
        ) : null}
      </head>
      <body className="min-h-full flex flex-col" suppressHydrationWarning>
        <I18nProvider dict={dict} locale={lang}>
          <Header locale={lang} dict={dict} />
          <main className="flex-1">{children}</main>
          <Footer dict={dict} />
        </I18nProvider>
      </body>
    </html>
  );
}
```

```ts
import type { Dictionary } from '@/i18n/dictionaries';
import type { CategoryKey } from './site';

// Metadados que NÃO são traduzíveis
export type ProjectMeta = {
  slug: string;
  status: 'concluido' | 'em-progresso' | 'em-breve';
  categories: CategoryKey[];
  date?: string;
  accent: 'blue' | 'orange' | 'pink';
  coverImage?: string;
};

// Projeto completo (metadados + traduções)
export type LocalizedProject = ProjectMeta & {
  title: string;
  subtitle: string;
  cardTitle?: string;
  description: string;
  intro: string;
  tags: string[];
  thanks: string;
  sections: {
    creationProcess: {
      title: string;
      paragraphs: string[];
    };
    prototyping?: {
      title: string;
      tabs: string[];
      captions: string[];
      images: { alt: string }[];
    };
    finalProject?: {
      title: string;
    };
  };
};

// Mapeamento slug → chave do dicionário
const slugToKey = {
  'pontos-sem-no': 'pontosSemNo',
  'batuco-tuco': 'batucoTuco',
  'pontinhas-soltas': 'pontinhasSoltas',
} as const;

// Metadados estáticos
const projectMeta: ProjectMeta[] = [
  {
    slug: 'pontos-sem-no',
    status: 'concluido',
    categories: ['grafico'],
    date: '08.12.2025',
    accent: 'blue',
    coverImage: '/images/projects/pontos-sem-no/cover.webp',
  },
  {
    slug: 'batuco-tuco',
    status: 'em-progresso',
    categories: ['interacao'],
    date: '04.12.2025',
    accent: 'orange',
    coverImage: '/images/projects/batuco-tuco/cover.png',
  },
  {
    slug: 'pontinhas-soltas',
    status: 'concluido',
    categories: ['3d'],
    date: '08.12.2025',
    accent: 'pink',
    coverImage: '/images/projects/pontinhas-soltas/cover.png',
  },
];

export function getLocalizedProject(
  slug: string,
  dict: Dictionary
): LocalizedProject | undefined {
  const meta = projectMeta.find((p) => p.slug === slug);
  if (!meta) return undefined;

  const key = slugToKey[slug as keyof typeof slugToKey];
  if (!key) return undefined;

  const i18n = dict.projects[key];

  return {
    ...meta,
    title: i18n.title,
    subtitle: i18n.subtitle,
    cardTitle: i18n.cardTitle,
    description: i18n.description,
    intro: i18n.intro,
    tags: i18n.tags,
    thanks: i18n.thanks,
    sections: {
      creationProcess: i18n.sections.creationProcess,
      prototyping: i18n.sections.prototyping,
      finalProject: i18n.sections.finalProject,
    },
  };
}

export function getLocalizedProjectsByCategory(
  category: CategoryKey,
  dict: Dictionary
): LocalizedProject[] {
  return projectMeta
    .filter((p) => p.categories.includes(category))
    .map((p) => getLocalizedProject(p.slug, dict)!)
    .filter(Boolean);
}

// Mantém compatibilidade com código existente
export const projectsByCategory = getLocalizedProjectsByCategory;
```

## 6. Padrões de Uso

### 6.1. Server Component (Page)

```tsx
// app/[lang]/page.tsx
import { getDictionary, isLocale } from '@/i18n/dictionaries';
import { notFound } from 'next/navigation';

export default async function HomePage({
  params,
}: {
  params: Promise<{ lang: string }>;
}) {
  const { lang } = await params;
  if (!isLocale(lang)) notFound();

  const dict = await getDictionary(lang);

  return (
    <div>
      <h1>{dict.home.greeting}</h1>
      <p>{dict.home.intro}</p>
    </div>
  );
}
```

### 6.2. Client Component

```tsx
'use client';

import { useTranslations } from '@/lib/i18n/use-translation';

export function SomeClientComponent() {
  const { t } = useTranslations();

  return <button>{t('contact.form.submitAriaLabel')}</button>;
}
```

### 6.3. Links com Locale

```tsx
// Sempre prefixar com /${locale}
<Link href={`/${locale}/contato`}>...</Link>

// Ou usar helper (futuro)
import { getLocalizedPath } from '@/i18n/routing';
<Link href={getLocalizedPath('/contato', locale)}>...</Link>
```

### 6.4. Metadata por Página

```tsx
// app/[lang]/contato/page.tsx
import type { Metadata } from 'next';
import { getDictionary, isLocale } from '@/i18n/dictionaries';

export async function generateMetadata({
  params,
}: {
  params: Promise<{ lang: string }>;
}): Promise<Metadata> {
  const { lang } = await params;
  if (!isLocale(lang)) return {};

  const dict = await getDictionary(lang);

  return {
    title: dict.metadata.contato,
    alternates: {
      languages: {
        'pt-BR': '/pt-BR/contato',
        en: '/en/contato',
      },
    },
  };
}
```

## 9. Tratamento de Casos Especiais

| Caso | Solução |
|------|---------|
| **Textos com JSX inline** (ex: `<strong>` no meio) | Quebrar em múltiplos keys: `body1`, `body1Bold`, `body1End` |
| **Textos com links inline** (ex: LinkedIn) | Quebrar: `beforeLink`, `linkText`, `afterLink` |
| **Pluralização** | Não necessário agora; adicionar `Intl.PluralRules` no futuro |
| **Datas** (ex: "08.12.2025") | Manter formato atual; usar `Intl.DateTimeFormat(locale)` no futuro |
| **Números** | Não há no momento; usar `Intl.NumberFormat(locale)` no futuro |
| **Imagens com texto** | Manter como estão (parte do design visual) |
| **Alt text de imagens** | Traduzir via dicionário (ex: `home.greetingAlt`) |
| **Formulário EmailJS** | Placeholders traduzidos; envio continua igual |
| **Mensagens de erro do form** | Todas no dicionário (`contact.form.errors.*`) |
| **Placeholders de projeto** ("Em breve") | No dicionário (`projects.comingSoon`) |
| **Status de projeto** | No dicionário (`status.concluido`, etc.) |
| **SEO hreflang** | `alternates.languages` em cada `generateMetadata` |
| **404 para locale inválido** | `notFound()` no layout se `!isLocale(lang)` |
| **Cookie de preferência** | `NEXT_LOCALE`, 1 ano de validade, `SameSite=Lax` |
